# Ressources et licences

Le logo Cognalys Intelligence a été fourni par le commanditaire. Il est conservé dans son fichier original et cadré dans un conteneur SVG, sans redessin ni recoloration. Les icônes d’interface, la composition et le monogramme C du favicon ont été créés pour ce projet. Aucun logo de client, faux témoignage ou photographie de banque d’images n’est intégré.

La police Manrope est fournie par `@fontsource-variable/manrope` et est distribuée sous la licence SIL Open Font License 1.1. Le texte est inclus dans `docs/Manrope-OFL.txt`. La police est servie localement par Next.js, sans requête vers Google Fonts.

Les dépendances restent régies par les licences de leurs auteurs, disponibles dans leurs paquets après `npm ci`. Le verrouillage exact est dans `package-lock.json`.

`public/og-image.svg` est la source vectorielle de l’image de partage `public/og-image.png`. `public/icon.svg` est la source du favicon et de l’icône Apple.
